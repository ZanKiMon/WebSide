# Kimoe Han · 个人作品集

「墨与冰 Ink & Ice」风格的个人作品集单页 —— React 19 + Tailwind CSS v4 + Vite 7。

**线上地址**：<https://zankimon.github.io/WebSide/>

## 本地运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建，输出到 dist/
```

## 更新内容

个人信息、项目列表、区块目录都集中在 **`src/data/site.js`** 一个文件里，照注释改即可。

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages（约 1 分钟生效）。
